# نسخهٔ بازطراحی‌شدهٔ پورتفولیوی مهسا اصغری

صفحهٔ اصلی این نسخه **مستقل** است: فونت‌ها، تصاویر، قالب، جلوه‌های متحرک و PDF دانلودی داخل خود index.html قرار دارند. حتی با آپلود همین یک فایل، ظاهر اصلی سایت و دانلود PDF در مرورگر دارای JavaScript کار می‌کنند.

برای جایگزینی کامل محتوای نسخهٔ قبلی، **روش کامل زیر پیشنهاد می‌شود**؛ چون PDF، صفحه و تصاویر قدیمی هم باید جایگزین شوند.

## به‌روزرسانی کامل سایت فعلی

۱. ZIP جدید را کاملاً Extract کنید.

۲. در مخزن mahsaasghari.github.io به Code → Add file → Upload files بروید.

۳. **تمام فایل‌ها و پوشه‌های داخل بسته** را با ساختار فعلی‌شان داخل کادر بارگذاری بکشید؛ خودِ ZIP یا یک پوشهٔ اضافی دور سایت را آپلود نکنید. index.html باید در ریشهٔ مخزن باشد.

۴. پوشه‌های assets، projects و scripts را هم بارگذاری کنید و Commit changes را بزنید. فایل‌های هم‌نام نسخهٔ قبلی باید جایگزین شوند.

۵. پس از تکمیل اجرای Pages در تب Actions، سایت را با Ctrl+F5 دوباره باز کنید. تنظیمات قبلی Pages روی main و /(root) باقی می‌ماند.

## چه چیزهایی تغییر کرده‌اند؟

- تمرکز سایت روی چهار پروژهٔ منتشرشده است.
- OCT فقط یک اشارهٔ کوتاه به یک ایدهٔ پژوهشی منتشرنشده دارد.
- صفحهٔ اصلی دارای قاب مداری، سه مطالعهٔ بصری متحرک و دکمه‌های توقف/ادامهٔ حرکت است.
- پروژه‌ها در خود صفحه باز می‌شوند؛ نیازی به بازشدن صفحهٔ جدا برای خواندن شکل‌ها نیست.
- PDF عمومی تازه و کوتاه‌تر فقط پروژه‌های منتشرشده را نمایش می‌دهد.

## جایگزین‌شدن نسخهٔ قدیمی OCT

بستهٔ جدید فایل‌هایی در مسیرهای قدیمی هم دارد تا با آپلود کامل، محتوای قبلی در نسخهٔ فعلی مخزن جایگزین شود:

- projects/polarization-sensitive-oct.html اکنون فقط یک جمله دربارهٔ ایدهٔ منتشرنشده دارد.
- فایل‌های قدیمی با پیشوند oct- در assets/images و assets/images/originals، **تصاویر خالیِ یک‌پیکسلی** هستند؛ شکل یا عکس پژوهشی در آن‌ها نیست و در سایت جدید نمایش داده نمی‌شوند. نام‌های قدیمی فقط برای جایگزینی فایل‌های قبلی حفظ شده‌اند.
- assets/documents/Mahsa_Asghari_Portfolio.pdf با PDF عمومی تازه جایگزین می‌شود.
- فایل BUILD_PROMPT.md، دادهٔ پروژه‌ها، اسکریپت تولید، فهرست تصاویر، توضیح منابع و تصویر تماس نیز نسخهٔ عمومی و تازه دارند.

**فقط تعویض index.html، فایل‌های قبلی در آدرس‌های مستقیمشان را جایگزین نمی‌کند.** برای انجام این بخش هم، کل بسته را طبق روش بالا بارگذاری کنید.

## پیش‌نمایش روی کامپیوتر

پس از Extract، روی index.html دوبار کلیک کنید. برای دیدن سایت نیازی به نصب برنامه یا اتصال اینترنت نیست. پیوند مقاله‌ها به سایت ناشر می‌رود. کپی خودکار ایمیل به پشتیبانی مرورگر بستگی دارد؛ در صورت نیاز پیام کپی دستی نمایش داده می‌شود.

## ویرایش‌های بعدی

برای ویرایش از منبع:

- scripts/site_content.json: معرفی، سوابق، داده‌های چهار مقاله و متن پروژه‌ها.
- scripts/templates/home.html: ساختار و متن‌های اصلی صفحه.
- assets/style.css: رنگ‌ها، تایپوگرافی و چیدمان.
- assets/site.js: تعامل‌ها و طرح‌های متحرک.
- assets/asset-manifest.json: مشخصات شکل‌های عمومی.

بعد از ویرایش، با Python استاندارد اجرا کنید:

    python scripts/generate_site.py
    python scripts/check_site.py

خروجی index.html را دوباره در GitHub جایگزین کنید. برای انتشار معمولی اجرای این دستورها لازم نیست؛ فایل آماده داخل بسته هست.

برای ساخت مجدد PDF عمومی:

    python -m pip install -r requirements.txt
    python scripts/make_public_pdf.py
    python scripts/generate_site.py
    python scripts/check_site.py

ساخت دوبارهٔ PDF باید پیش از تولید HTML انجام شود تا نسخهٔ جدید آن داخل فایل اصلی هم قرار بگیرد.

## بدون JavaScript

اطلاعات، تصاویر و بخش‌های بازشدنی مقاله‌ها همچنان قابل استفاده‌اند. طرح‌های متحرک، فیلتر، بزرگ‌نمایی و کپی ایمیل به‌صورت بهبودهای اختیاری اضافه می‌شوند. لینک معمولی PDF در این حالت از پوشهٔ assets/documents استفاده می‌کند؛ بنابراین برای دانلود PDF بدون JavaScript، بستهٔ کامل را بارگذاری کنید.

نیازی به npm، build، API key، حساب اضافی یا سرویس پولی نیست.
